# M5 — 不对称负载 + 按重量均衡（8 重 / 8 轻，8 轮）

## 问题
两卡 program 数量相同但重量不同（重 17.6K token / 轻 4.4K token），全部在容量内。
问：按"被钉住的上下文 token"做均衡，能不能把轻卡的空转压下来？

## 为什么要换信号
`vllm:kv_cache_usage_perc` 在空闲时报 0（不统计 prefix cache 保留块）。有工具延迟时两卡大部分
时间都在等工具，于是 hot/cold 差恒为 0，平衡器连续三次"没动"——不是保守，是**量错了**。
改用 `Σ pinned prompt_tokens`（executor 自己的 pin 表）后，105,304 token 的偏差立刻可见。

## 结果（8 runs，唯一变量 EXECUTOR_BALANCE）

| 臂 | 各次 wall (s) | wall 均值 | 各次 b 空转 (s) | 空转均值 | 迁移次数 |
|---|---|---|---|---|---|
| off | 156.34 / 128.35 / 126.40 / 146.93 / 124.18 | 136.44 | 57.04 / 22.45 / 37.76 / 42.56 / 6.48 | 33.26 | 0 |
| skew | 113.11 / 111.86 / 115.66 | 113.54 | 13.40 / 14.55 / 24.01 | 17.32 | 3 / 3 / 3 |

- wall −16.9%，空转 −48%，16/16 成功、0 失败。
- 方差收窄更值钱：off 空转跨度 50.6 s，skew 跨度 10.6 s。
- 三次 skew 都走同一条路径：held 差 ≥ 半容量门槛 → 搬 3 个最大可搬程序 → 收敛到 252 token（0.22%）→ 停手。

## 边界（不要过度解读）
- 对照是"我们的 off 臂"，**不是裸 ThunderAgent**；TA 头对头尚未在本场景跑。
- N=40 容量墙问题未解（TA 能跑完、我们停住）。
- 收益来自"亲和 + 按字节均衡"，**不是 KV block 迁移**——本栈没有搬运通道（M0 结论），搬的是 pin + 重算。

## 复现
```
EXECUTOR_BALANCE=skew EXECUTOR_BALANCE_GAP_FRACTION=0.10 EXECUTOR_BALANCE_INTERVAL=2.0 \
  python3 -m uvicorn executor.app:app --host 127.0.0.1 --port 8100
python3 tests/asym_skew.py <label>        # HEAVY, LIGHT, TURNS = 8, 8, 8
```
数据：`data/m5_asym.csv`。


## 三方对照（同一 8 重 / 8 轻、8 轮、工具延迟 2-20 s）

| 臂 | 各次 wall (s) | wall 均值 | 相对 TA | 各次轻卡空转 (s) | 说明 |
|---|---|---|---|---|---|
| 裸 ThunderAgent (9001 -> 8022/8023) | 111.09 / 122.12 / 116.45 | **116.55** | - | 5.28 / 2.95 / -10.97* | 自身按容量放置，无需外部平衡 |
| 我们 off（只按 pin 数，不均衡） | 156.34 / 128.35 / 126.40 / 146.93 / 124.18 | **136.44** | +17.1% | 57.04 / 22.45 / 37.76 / 42.56 / 6.48 | 重 program 落哪张卡决定尾巴 |
| 我们 skew（按 held token 均衡） | 113.11 / 111.86 / 115.66 | **113.54** | -2.6% | 13.40 / 14.55 / 24.01 | 每次搬 3 个，收敛到 252 token |

\* 负值表示轻卡反而最后完成（早完成量为负），按"另一张卡的空转"读。

**结论**：字节均衡把 off 臂相对 TA 的 +17.1% 差距压到 -2.6%（即在噪声内打平，方向略优）。
但空转尾巴仍是 TA 最小（~4 s vs ~17 s）：TA 从放置阶段就按容量摊开重 program，
我们靠事后搬迁，搬迁发生在时间轴上偏晚，尾巴收不干净。

数据：`data/m5_asym.csv`；TA 臂用 `scripts/ta_launch.py --port 9001` + `tests/asym_skew.py <label> noseed`。
